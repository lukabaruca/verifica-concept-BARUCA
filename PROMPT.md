Ruolo: studente ITS incaricato del controllo di dati.

Contesto: analizza i fogli Concept, Pesi_CS01 e Registro di un file Excel contenente battelli da addestramento. Le unità sono quelle indicate nelle intestazioni.

Compito:
- individua dati mancanti
- individua valori fuori scala
- individua celle con formato errato
- individua righe duplicate
- individua date non valide

Formato di uscita:
tabella con colonne:
foglio, posizione, valore letto, problema riscontrato.

Vincoli:
non inventare dati mancanti.
Se il dato corretto non è noto, scrivi "non presente".
Non eseguire calcoli di stabilità, potenza o normativa.
